Script utilizado para realizar o parsing de disciplinas da UFABC. O objetivo é identificar quais disciplinas, das que estão sendo ofertadas, são obrigatórias e/ou limitadas dos cursos de Ciência da Computação (BCC) e Ciência de Dados (BCD).

Os arquivos analisados (PDFs de matrículas e planilhas de planejamento, como "Turmas 2027.3.xlsx") ficam na pasta `arquivos_analise`. O output vem em formato de arquivos TXT básicos na pasta `analise_disciplinas`, um para cada arquivo analisado.
